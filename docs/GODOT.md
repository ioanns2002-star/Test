# Godot viewer

Это самостоятельный просмотрщик для Godot **4.3+**. Откройте в Project Manager файл
`godot/project.godot` и запустите проект (`F6`/`F5`). По умолчанию включён
**Compatibility** renderer, поэтому проект не требует мощной видеокарты.

Перед запуском сборка должна положить рядом с проектом два генерируемых файла:

```text
godot/assets/scene.glb
godot/assets/scene-manifest.json
```

`scene.glb` — тот же экспорт Blender, который использует веб-просмотрщик. Если файл
не скопирован или повреждён, вместо молчаливого пустого экрана появится понятное
сообщение в интерфейсе. Не добавляйте эти производные файлы в Git: каталог уже
игнорирует их.

## Управление

1. На первом экране курсор **не захватывается**. Нажмите **«Войти в сцену»**.
2. `WASD` или стрелки — движение, мышь — обзор, `Shift` — быстрее.
3. `R` — вернуть камеру к референсной точке, `T` — включить/выключить дождь,
   `Esc` — освободить курсор, `F1` — скрыть подсказку.

Границы движения считываются из `bounds.min/max` manifest (текущие: `x = .20…1.16`,
`y = 1.65`, `z = -18.6…1` в системе Godot). Дождь создаётся локально через
`CPUParticles3D` только с внешней стороны (`x > 2`). Значения тумана и локальных
источников также читаются из `lighting`; текущий exit-light — `(.8, 3.10, -19.25)`.

## Manifest камеры

В сборке нужен объект `camera`; его координаты по умолчанию уже в Godot (`Y` вверх,
вглубь коридора — отрицательный `Z`):

```json
{
  "coordinate_space": "godot",
  "camera": {
    "position": [0.77, 1.65, 0.0],
    "target": [4.66, 0.92, -18.7],
    "fov": 40.34,
    "near": 0.06,
    "far": 350
  },
  "bounds": {
    "min": [0.20, 1.65, -18.6],
    "max": [1.16, 1.65, 1.0]
  },
  "lighting": {
    "fogColor": "#718793",
    "fogNear": 10,
    "fogFar": 220,
    "exitLight": [0.8, 3.10, -19.25],
    "stepLights": [[0.24, 0.38, -7.8], [0.24, 0.38, -14.0]]
  }
}
```

Помимо `camera`, рантайм использует `bounds` и `lighting` из полного manifest:
`fogColor`, `fogNear`, `fogFar`, `exitLight`, `stepLights`. Если эти поля неверны
или отсутствуют, остаются безопасные запасные значения. После импорта GLB камера
игрока принудительно становится текущей, поэтому встроенная `Camera_Reference` не
перехватывает обзор; `R` повторно применяет текущие значения manifest и возвращает
эту же камеру в активное состояние.

`fov` интерпретируется как вертикальный угол обзора: камера явно использует
`KEEP_HEIGHT`. Начальное окно имеет соотношение сторон `1.4`, как и референсная
камера (`735 × 525`); при произвольном изменении размера окна горизонтальная
композиция естественно изменится.

Если исходные значения записаны прямо в Blender (`X`, `Y` глубина, `Z` вверх),
укажите `"coordinate_space": "blender"`: просмотрщик переведёт их в
`(x, z, -y)`.

GLB передаёт геометрию и экспортируемые материалы. Свет, туман, частицы и тонмаппинг
в Godot настроены для похожего дождливого настроения, но это не эквивалент Cycles и
не заявление о пиксельно-точной копии исходной фотографии. В проекте нет внешних
CDN или сторонних ассетов.

## Проверка рантайма

После подготовки `assets/` можно выполнить:

```bash
godot --path godot --script res://tests/verify_scene.gd
```

Проверка действительно импортирует GLB, сверяет камеру с manifest, переключает
дождь, имитирует `W` и возвращает камеру. При ошибке код завершения ненулевой.
Ей нужен графический контекст: в `--headless` Godot не захватывает мышь, поэтому
проверка прогулки там не работает. На Linux-сервере используется
`xvfb-run -a godot --audio-driver Dummy --path godot --script res://tests/verify_scene.gd`.
